// ARCHITECTURE & FEATURES

The Complete
AI Coach System

A full-stack, real-time AI fitness coach combining high-precision computer vision, biomechanical kinematics, ultra-fast LLM reasoning, and natural voice guidance.

01 / COMPUTER VISION
👁️

MediaPipe Vision Engine

Ingests real-time video frames through Streamlit WebRTC at 30+ FPS. Leverages Google's MediaPipe Pose Landmarker model to track 33 spatial landmarks in 3D coordinates with zero wearable sensors.

OpenCV · MediaPipe · WebRTC
02 / BIOMECHANICS
📐

Kinematic Form Detectors

Computes joint angles (knee flexion, hip hinge, elbow drift, shoulder extension) in real-time. Includes state machines for Squats, Push-ups, Biceps Curls, Shoulder Press, and Lunges with strict depth & safety validation.

Vector Geometry · Angular Kinematics
03 / REAL-TIME AI
🎙️

Groq LLM Voice Coach

Powered by Groq Cloud with ultra-fast inference using openai/gpt-oss-120b & gpt-oss-20b. Synthesizes motivational coaching cues and corrective voice guidance via Edge TTS whenever form faults occur.

Groq Cloud · Sub-second LPU · Edge TTS
04 / PERSISTENCE
📊

Session Analytics & DB

Persists athlete workouts in a lightweight SQLite repository. Logs timestamped sets, completed reps, time elapsed, and exercise history under unique user profiles for progressive fitness overload.

SQLite · Session State · Pandas
